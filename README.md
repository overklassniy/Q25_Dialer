## About

**Q25 Dialer** is a modern Android dialer specifically designed for the **[Zinwa Q25](https://en.wikipedia.org/wiki/Zinwa_Q25)** – a unique QWERTY keyboard smartphone that brings back the iconic BlackBerry Classic form factor with modern internals.

The app is optimized for the Q25's distinctive **720×720 square display** and **physical QWERTY keyboard**, providing a seamless dialing experience that traditional dialer apps cannot match.

## Development

### Requirements

- Android Studio Otter or newer
- JDK 21
- Android SDK 36
- Minimum Android version: 8.0 (API 26)

### Building the Project

```bash
# Clone the repository
git clone https://github.com/overklassniy/Q25_Dialer.git
cd Q25_Dialer

# Build the project
./gradlew assembleDebug

# Or open in Android Studio
```
